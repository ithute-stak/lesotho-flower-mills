# Phase 8 — Quotations (initial, staff-controlled)
- Staff creates draft quotations using verified database customer, published price book and active products.
- Server computes quantity pricing and stores totals, SKU/name snapshots, expiry date and creator.
- Staff can retrieve records and generate draft PDF quotations.
- No customer-entered prices and no public quotation route.
- No taxes, delivery fees, payment links, checkout or confirmed orders. PDF explicitly marks these omissions.
- Current draft quotation PDF is not yet an official tax invoice or accepted quotation.
- Customer-to-price-book assignment, document templates, approval/issuance, and inventory verification are required before production.
